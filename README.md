# 快速截图 QuickShot

一个极简的 macOS 菜单栏截图工具：点一下（或按快捷键）就出十字光标，**直接拖动框选，松手即截图**，不用再调整选框。

## 功能
- 菜单栏图标：左键直接截图，右键打开菜单
- 全局快捷键，默认 `⌘⇧2`，可在「设置快捷键…」里自定义（不需要辅助功能权限）
- 截图保存到 `~/Pictures/Screenshots/`，同时复制到剪贴板
- 右下角弹出缩略图：单击用预览打开，可直接拖进其他 App，悬停不消失，5 秒后自动收起
- 开机自动启动（菜单里勾选）

## 安装
需要 Xcode 命令行工具（`xcode-select --install`）。

```bash
./build.sh
```

首次截图时按提示在「系统设置 → 隐私与安全性 → 屏幕与系统录音」中允许「快速截图」。
