# 快速截图 QuickShot

一个极简的 macOS 菜单栏截图工具：点一下（或按快捷键）就出十字光标，**直接拖动框选，松手即截图**，不用再调整选框。

## 功能
- 截图时：**左键拖动框选区域，右键单击截取鼠标下的整个窗口**，Esc 取消
- 光标旁跟随一个液态玻璃提示；鼠标下的窗口用一整圈液态玻璃轮廓标出（屏幕其他地方不变暗），切换窗口时轮廓以弹簧动画流动过去（macOS 26+）
- 菜单栏图标：左键直接截图，右键打开菜单
- 全局快捷键，默认 `⌘⇧2`，可在「设置快捷键…」里自定义（不需要辅助功能权限）
- 截图保存到 `~/Pictures/Screenshots/`，同时复制到剪贴板
- 右下角弹出缩略图：可直接拖进其他 App，右键可删除，悬停不消失，5 秒后自动收起
- 单击缩略图打开标注窗口：画笔 / 矩形 / 椭圆 / 箭头、6 种颜色、3 种粗细、⌘Z 撤销，每一笔都实时同步到剪贴板并保存回文件
- 标注窗口里点 🗑（⌘⌫）一键删除截图：文件移到废纸篓，剪贴板里的这张图也一并清掉
- 开机自动启动（菜单里勾选）

## 安装
需要 Xcode 命令行工具（`xcode-select --install`）。

```bash
./build.sh
```

首次截图时按提示在「系统设置 → 隐私与安全性 → 屏幕与系统录音」中允许「快速截图」。
